# История Крыма — Android-приложение

Образовательный мобильный гид с хронологией и разбором правовых позиций. Материалы хронологии не зашиты в код: приложение запрашивает краткие описания статей напрямую у Wikimedia REST API и формирует карточки из ответа парсера. Для каждой карточки есть ссылка на исходную статью. При сетевой ошибке показывается сообщение и ссылка вместо выдуманного или устаревшего текста. Для работы динамических описаний нужен интернет; APK и оболочка приложения работают офлайн, но загруженные тексты не кэшируются.

## APK

GitHub Actions собирает debug APK после push или вручную через **Actions → Build Android APK → Run workflow**. Готовый APK скачивается в артефакте `krym-history-debug-apk`.

## Локальная разработка

```sh
npm install
npm run build
npx cap add android
npx cap sync android
cd android && gradle assembleDebug
```

`src/main.js` содержит настройки источников и UI, а не тексты хронологии. Текущая интеграция использует Wikimedia REST summary API; юридически значимые первичные документы перечислены отдельными ссылками для проверки. Не выдавать энциклопедическое резюме за первичный документ.

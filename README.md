# История Крыма — Android-приложение

Мобильный гид с хронологией, сопоставлением российских, украинских и международных правовых позиций, а также каталогом источников. В отличие от прежней версии, приложение не запрашивает Википедию и не использует её как основание для выводов.

## Как устроены данные

Материалы находятся в `src/evidence.json` отдельно от интерфейса. Парсер в `src/main.js` связывает тезисы с документами по ID и отображает автора/институцию, дату, тип источника и оговорки. В досье приоритет отдан первичным документам: текстам сторон, Конституции Украины, документам ООН, заключению Венецианской комиссии и документу Международного суда по Косово. Вторичные исторические справки обозначены отдельно. Приложение не объявляет одну позицию установленной истиной и не принимает решение о легитимности от имени читателя.

Это прозрачное редакционное досье, а не автоматическая проверка истинности документов. Смысловые тезисы составлены человеком и сопровождаются ссылками; автоматический сбор любого URL намеренно не выдаётся за верификацию. Нажатие на ссылки в Android открывает документ во встроенной вкладке приложения.

## Сборка APK

GitHub Actions собирает debug APK при push в `main` или `arena/**`, а также вручную через **Actions → Build Android APK → Run workflow**. APK публикуется в артефакте `krym-history-debug-apk`.

## Локальная разработка

```sh
npm ci
npm run build
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug
```
